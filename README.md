# GAVA Telegram-бот

Полноценный русскоязычный игровой Telegram-бот с внутренней валютой GAVA.

## Что реализовано

- Начальный баланс 0 GAVA.
- Ежедневный бонус 100 000 GAVA раз в 24 часа.
- Баланс в личных чатах и группах через `б` или `баланс`.
- Переводы ответом на сообщение: `п 100000`.
- Команда `топ` показывает 10 игроков с самым большим балансом.
- Игры `мина`, `кубик`, `монета`, `дартс`, `слот`.
- MINES: поле 6×6, ровно 6 случайных бомб, множители и безопасный вывод выигрыша.
- Дуэли ответом на сообщение: `дуэль 100000`.
- Промокоды вида `#GAVA100` в личных чатах и группах.
- После успешной активации промокода показывается счётчик оставшихся активаций в формате `осталось/всего`.
- Админ-панель `/admin` с созданием, просмотром и включением/выключением промокодов.
- Администратор может искать пользователей, просматривать их данные, менять баланс, выдавать и отзывать бонусы, блокировать и разблокировать аккаунты.
- В группе команда `б` показывает кнопку `🎁 Бонус`, если бонус доступен именно этому пользователю.
- SQLite с транзакциями, уникальным погашением промокодов и сохранением состояния игр.
- Все игровые кнопки проверяют пользователя, игру, статус и ход.
- Постоянная Reply Keyboard и команда `/menu` не используются.

## Настройка в Replit

1. В Secrets добавьте:
   - `BOT_TOKEN` — токен бота от BotFather. В текущем проекте также поддерживается уже сохранённый `TELEGRAM_BOT_TOKEN`.
   - `ADMIN_ID` — Telegram ID администратора.
2. Установите зависимости из `requirements.txt`.
3. Запустите:

```bash
python bot.py
```

В Replit должен работать фоновый workflow с этой командой.

Для работы после закрытия редактора одного фонового workflow недостаточно: опубликуйте проект как **VM / Always Running** через Publishing. Именно VM-публикация предназначена для Telegram-ботов и фоновых процессов. Если проект не опубликован, рабочий процесс может остановиться после завершения сессии Replit.

## BotFather и группы

Создайте бота через BotFather и вставьте его токен в Secrets. Для обработки обычных текстовых триггеров в группах (`б`, `мина 100000`, `#GAVA100`) у бота может потребоваться отключить Privacy Mode через BotFather командой `/setprivacy`. Администратором группы бот быть не обязан, если функция Telegram доступна при текущих правах.

## Данные

База `gava.sqlite3` создаётся автоматически. Балансы, транзакции, бонусы, активные игры, дуэли и промокоды переживают перезапуск процесса.

Баланс ограничен безопасным пределом SQLite INTEGER. Все суммы проверяются как положительные целые числа и не могут сделать баланс отрицательным.

## Панель администратора

Откройте `/admin` с аккаунта администратора. Доступны:

- список и поиск пользователей по ID или username;
- просмотр имени, username, ID, баланса, бонусов, реферера и статуса;
- добавление, снятие и установка баланса;
- добавление и отзыв доступных бонусов;
- блокировка и разблокировка пользователя;
- статистика пользователей, игр, промокодов, использованных и оставшихся активаций.
